checklist Active Policy Rules

CONFIDENCE MAJORITY RULE
ML model confidence contributes 60% to the final risk score. High-confidence attack predictions can push the score above threshold without relying solely on behavioral history.
ESCALATION GUARD
IPs with a rising attack frequency score are automatically elevated to a minimum ALERT status, bypassing lower thresholds regardless of current risk score.
FALSE POSITIVE PROTECTION
IPs previously marked as false positives receive a rate-limit response instead of a block on subsequent detections, protecting against misclassification of benign traffic.
BURST DETECTION
Any IP that sends more than 100 requests within a 5-minute window is immediately blocked, regardless of ML confidence. This prevents volumetric DDoS attacks from flooding the system.
STRICT MODE TRIGGER
After 3 confirmed block events, an IP enters strict mode. All subsequent attack detections from that IP trigger an immediate block response with no intermediate steps.
