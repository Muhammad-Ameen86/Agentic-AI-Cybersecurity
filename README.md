# Agentic AI Cybersecurity

AI-powered cybersecurity detection platform using:
- FastAPI
- Machine Learning
- LangChain
- WebSocket
- CIC-IDS2017
- UNSW-NB15

## Features
- Intrusion detection
- Real-time prediction
- Dashboard analytics
- Multi-model evaluation
- Agentic AI reasoning

## Project Structure
Backend/
ML/
Docs/

## Installation

### Create venv
python -m venv venv

### Activate
venv\Scripts\activate

### Install
pip install -r requirements.txt

## Run Backend
uvicorn Backend.app.main:app --reload
